# 🏦 Bank System (C++ OOP)

A console-based banking system developed using C++ and Object-Oriented Programming concepts.  
The system simulates real-world banking operations such as account management, transactions, and user authentication.

---

## 🚀 Features

- Create new bank accounts
- Deposit and withdraw money
- View account details
- Transfer money between accounts
- Delete accounts
- Admin control panel

---

## 🧠 Concepts Used

- Object-Oriented Programming (OOP)
  - Classes & Objects
  - Encapsulation
  - Inheritance
- File Handling
- Data Structures (if used)
- Modular Design

---

## 🛠 Technologies

- C++
- Console Application
- File System (for data storage)
